# moon-negotiator

Small HTTP content negotiation utilities for MoonBit.

This project is being developed for the 2026 MoonBit September Hackathon.

## Planned v0.1

- Parse `Accept`
- Parse `Accept-Encoding`
- Parse `Accept-Language`
- Select compatible server representations
- Test q-values, wildcards, specificity, and edge cases

The library focuses only on content negotiation. It does not provide an HTTP server or middleware framework.
